# Política de segurança

## Versões suportadas

O projeto está em desenvolvimento acadêmico. Correções são aplicadas na branch
`main`.

## Como reportar uma vulnerabilidade

Não abra uma issue pública para problemas de segurança. Use o recurso
[Security Advisories](https://github.com/enzo-barbosa/GeoRural/security/advisories/new)
do GitHub para relatar de forma privada.

Inclua, se possível:

- descrição do problema e impacto;
- passos para reproduzir;
- versão/commit afetado;
- sugestão de correção.

O retorno será dado pelo mantenedor do repositório. Credenciais, chaves do
Earth Engine e o arquivo `.env` nunca devem ser enviados em issues, PRs ou
logs.
