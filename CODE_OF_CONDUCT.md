# Código de Conduta

Este projeto segue o [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Nosso compromisso

Contribuir para um ambiente aberto, acolhedor e livre de assédio, independente
de idade, aparência, deficiência, etnia, identidade de gênero, nível de
experiência, nacionalidade, religião ou orientação sexual.

## Comportamentos esperados

- Ser respeitoso e construtivo em revisões e discussões.
- Aceitar críticas técnicas com abertura.
- Focar no que é melhor para o projeto e para o aprendizado do grupo.
- Dar crédito ao trabalho dos colegas.

## Comportamentos inaceitáveis

- Assédio, discriminação, ataques pessoais ou comentários depreciativos.
- Publicação de informações privadas sem consentimento.
- Uso do espaço do projeto para fins alheios ao escopo acadêmico.
- Qualquer conduta inadequada em issues, PRs, commits ou canais do grupo.

## Aplicação

O mantenedor do repositório pode remover comentários, fechar issues/PRs ou
tomar outras medidas cabíveis. Relatos podem ser feitos de forma privada ao
mantenedor pelo GitHub.

## Atribuição

Este código é adaptado do Contributor Covenant, versão 2.1.
